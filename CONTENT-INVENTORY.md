## Additional preview pages

- `visit.html` retains the approved first-visit overview and FAQs, with links to the redesigned contact and prayer pages.
- `gallery.html` contains all nine original homepage gallery photographs with keyboard-accessible enlargement. The remaining two source photographs appear in the Bible/teaching sections. All 11 photos are local assets; sources are documented in `assets/sources.json`.

## Intentional adaptations

- The Easter April 4–5, 2026 announcement is preserved under **Past event**, including the egg hunt, Sunday times, and no-evening-activities notice. It is not advertised as upcoming.
- Contact/prayer form fields match the source forms. GitHub Pages has no Squarespace form backend. **Review email draft** creates a local review panel, and **Open in email app** opens a draft for the visitor to send. No submission, storage, or successful-delivery claim occurs on the preview. The existing church web forms remain linked as alternatives.
- Giving uses the exact church Tithe.ly destination. No payment details are collected by this repository.
- The calendar remains tied to the church's existing Google Calendar. The preview does not invent special events or copy a stale calendar month.
- Copy is organized into readable sections. Minor punctuation and capitalization are normalized. No staff names, ministry times, or doctrinal claims have been invented.
- Squarespace-only cart/system paths and theme code are not church content and are not reproduced.
- Search engines are instructed not to index the test pages. This does not make the public GitHub repository private.

## Future Squarespace work

All current original page URLs should be retained when this design is eventually rebuilt in Squarespace. Native forms and calendar blocks can replace the static preview adaptations. See `SQUARESPACE-HANDOFF.md`; no migration has been performed.
